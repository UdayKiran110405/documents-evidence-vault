# Multi-Region Document Evidence Vault & Recovery Drill

## Project Overview

A secure document storage and recovery application designed to
protect digital documents through version management, integrity
verification, retention policies and multi-region disaster recovery.

## Technology Stack

- Frontend: React
- Backend: Java and Spring Boot
- Authentication: Spring Security and JWT
- Database: MySQL
- Object Storage: AWS S3
- Independent Verification: Python and FastAPI
- Containerization: Docker and Docker Compose
- Infrastructure as Code: Terraform
- CI/CD: GitHub Actions
- Analytics: Snowflake and Power BI

## AWS Regions

- Primary: Mumbai (ap-south-1)
- Secondary: Singapore (ap-southeast-1)

## Project Modules

- User Authentication and Authorization
- Document Management
- Version Management
- Document Integrity Verification
- Retention and Protection
- Multi-Region Replication
- Disaster Recovery
- Audit Logging
- Monitoring and Analytics

## Development Environment

The application is initially developed and tested locally.
AWS infrastructure will be introduced after local implementation
and verification.

## Project Structure

- frontend: React application
- backend: Spring Boot application
- verifier: Python verification service
- infrastructure/terraform: AWS infrastructure configuration
